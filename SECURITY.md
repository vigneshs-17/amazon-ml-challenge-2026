# Security Policy

## Reporting a Vulnerability

If you discover a potential security vulnerability in this repository, please report it via GitHub's private vulnerability reporting feature:

1. Navigate to the **Security** tab of this repository on GitHub.
2. Under **Reporting**, click **Report a vulnerability** to open an advisory draft.

Please do not disclose security issues through public GitHub issues, pull requests, or discussions.

## Response SLA

Vulnerability reports are handled on a best-effort basis, with an aim to acknowledge and respond within 7 days.
